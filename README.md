# User Registration CRUD

A simple User Registration CRUD application built using HTML and JavaScript.

📌 Description

This project allows users to:

- Register user details
- View registered users
- Edit user information
- Delete user records

The data is currently stored temporarily in the browser (without a database).

🛠️ Technologies Used

- HTML5
- JavaScript

📁 Project Structure

```
User-Registration-CRUD/
│── index.html
│── script.js
```

▶️ How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Start using the application.

 📋 Features

- Create User
- Read User Details
- Update User Details
- Delete User Details

 🚧 Future Improvements

- Connect to a database (MySQL)
- Add Backend (Node.js/Express or PHP)
